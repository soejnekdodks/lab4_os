# ЛР4 по операционным системам

Скрипты Bash строят пять отчётов по файловой системе преподавателя из ЛР3. Можно вызвать нужную команду, выбрать функцию в текстовом меню или открыть окна Linux Dialog.

## Быстрый запуск

Откройте терминал в корне проекта, рядом с `lab4.sh`. В репозитории есть каталог `labfiles-3-26`. Для проверки другой копии данных замените путь в первой строке. Кавычки нужны, если в пути есть пробелы.

```bash
DATA="./labfiles-3-26"
bash lab4.sh help
bash lab4.sh menu "$DATA"
```

В меню выберите номер функции. В меню и в прямых командах для подсчёта попыток и лучших результатов можно ввести `1` (Цирковое дело) или `2` (Пересдачеведение). После отчёта меню откроется снова. Пункт `0` и Ctrl+D завершают сеанс.

## Команды

| Режим | Пример | Что выводит |
| --- | --- | --- |
| Лидеры по оценкам | `bash lab4.sh top "$DATA" A-06-21` | По одному лидеру для 5, 4 и 3 по обоим предметам и четырём тестам, с перечнем попыток. Знаки после оценки отбрасываются. При равенстве выбирается первый в списке группы. |
| Число попыток | `bash lab4.sh tries "$DATA" A-06-21 Цирковое_Дело 1` | Всю группу по убыванию числа попыток, включая неуспешные. У студентов без попыток выводится 0. При равенстве сохраняется порядок файла группы. |
| Досье | `bash lab4.sh dossier "$DATA" Anasenko` | Все заметки для ФИО с указанным началом. Регистр букв учитывается. |
| Лучшие по годам | `bash lab4.sh best "$DATA" Цирковое_Дело` | По одному лидеру среди всех групп за каждый год, по сумме правильных ответов и с разбивкой по тестам. Учитываются попытки с оценками 3–5. При равенстве остаётся первый встретившийся результат. |
| Посещаемость | `bash lab4.sh attend "$DATA" A-06-21 1 18` | По каждому предмету отдельно, в порядке убывания числа посещений. Интервал задаётся номерами пар от 1 до 18 включительно. |

Команды `top` и `best` проверяют наличие всех восьми файлов тестов до расчёта. Код завершения `0` означает успешный запрос, в том числе пустую выборку, `1` означает ошибку ввода, `2` означает проблему с данными.

## Формат данных

Списки групп лежат в `students/groups/<группа>`, досье в `students/general/notes/*.log`. В каталогах `Цирковое_Дело` и `Пересдачеведение` программа читает `tests/TEST-1` … `tests/TEST-4` со строками `группа;ФИО;дата;правильные_ответы;оценка`. Файлы `<группа>-attendance` содержат ФИО, пробел и строку из 18 нулей и единиц.

## Интерфейс Linux Dialog

Dialog рисует окна в терминале. Рабочий стол Linux и X11 не требуются. Рядом со скриптом `dialog.sh` должны лежать `lab4.sh` и `dialog.rc`. Выбирайте пункты стрелками, подтверждайте клавишей Enter. Esc и Cancel возвращают из запроса в главное меню. Ctrl+D завершает программу. Если путь опустить, появится окно ввода. Если окно не помещается, увеличьте размер терминала.

### Если у вас Linux

Откройте терминал. На Debian или Ubuntu установите Dialog и запустите меню:

```bash
sudo apt update
sudo apt install dialog
cd /путь/к/lab4_os
bash dialog.sh "/путь/к/labfiles-3-26"
```

На другом дистрибутиве установите пакет `dialog` его штатным менеджером пакетов, затем выполните последние две команды.

### Если у вас Windows

Проще всего запустить Linux через WSL. Если WSL ещё нет, откройте PowerShell **от имени администратора**, выполните команду ниже и перезагрузите компьютер:

```powershell
wsl --install
```

После перезагрузки откройте Ubuntu и создайте пользователя, если программа попросит. В появившемся терминале выполните:

```bash
sudo apt update
sudo apt install dialog
cd "/mnt/c/Users/ВАШЕ_ИМЯ/путь/к/lab4_os"
bash dialog.sh "/mnt/c/Users/ВАШЕ_ИМЯ/путь/к/labfiles-3-26"
```

Путь `C:\Users\...` внутри WSL начинается с `/mnt/c/Users/...`. Для диска `D:` используется `/mnt/d/`. Если проект и данные уже лежат в домашнем каталоге Ubuntu, используйте их обычные Linux-пути.

### Если у вас macOS

Установите и запустите Docker Desktop. Откройте Terminal и перейдите в каталог проекта. Затем укажите путь к данным и запустите временный Linux-контейнер:

```bash
cd "/путь/к/lab4_os"
DATA_DIR="/путь/к/labfiles-3-26"
docker run --rm -it -e TERM=xterm -e LANG=C.UTF-8 \
  -v "$PWD:/work:ro" -v "$DATA_DIR:/data:ro" \
  -w /work debian:bookworm-slim \
  bash -lc 'apt-get update -qq && apt-get install -y -qq dialog && bash dialog.sh /data'
```

При первом запуске Docker загрузит Linux-образ. Каталоги проекта и данных подключаются к контейнеру только для чтения. После выхода контейнер удаляется; при следующем запуске команда снова установит `dialog` внутри нового контейнера.
