# ЛР4 по операционным системам: обработка файловой системы преподавателя

Проект бригады по ЛР4: Bash-решение, которое обрабатывает файловую систему
преподавателя из ЛР3 (каталог вида `labfiles-3-26`) и отвечает на запросы
о результатах тестирования, попытках сдачи, досье и посещаемости студентов.

Исходные данные в репозиторий не входят: скрипт получает путь к каталогу
данных параметром при запуске.

## Возможности

Обязательные:
- **top** — по номеру группы: студенты с максимальным количеством пятёрок,
  четвёрок и троек по тестам;
- **tries** — по номеру группы: список группы, упорядоченный по количеству
  попыток сдачи теста.

Дополнительные:
- **dossier** — по фамилии: досье студента из заметок преподавателя;
- **best** — по номеру группы: лучшие результаты (по количеству правильных
  ответов) за каждый год сдачи теста;
- **attend** — по номеру группы и интервалу: список студентов, упорядоченный
  по средней посещаемости за интервал.

## Запуск

```
./lab4.sh <режим> <путь_к_данным> [параметры режима]
```

Режимы:
- `top <группа>` — лидеры по количеству 5, 4 и 3 по тестам
- `tries <группа>` — список группы по количеству попыток
- `dossier <фамилия>` — досье по фамилии
- `best <группа>` — лучшие результаты за каждый год
- `attend <группа> <нач> <кон>` — средняя посещаемость за интервал
- `help` — справка

Коды завершения: `0` — успех, `1` — неверные аргументы,
`2` — данные или группа не найдены, `3` — режим не реализован.

Примеры:

```
./lab4.sh help
./lab4.sh top /path/to/labfiles-3-26 A-06-21
./lab4.sh attend /path/to/labfiles-3-26 A-06-21 1 18
```

## Ограничения реализации

Решение написано на чистом Bash с использованием только средств, изученных
в курсе: переменные, условия, циклы, массивы, арифметика `$(( ))`, проверки
файлов, `grep`, `sed`, базовый `sort`. Внешние интерпретаторы (`awk`, `python`,
`jq` и т. п.) не используются. Комментарии и сообщения — на русском языке.

## Статус

Реализован каркас: разбор аргументов, проверка пути к данным и группы,
справка. Режимы добавляются последовательно, см. историю коммитов.
