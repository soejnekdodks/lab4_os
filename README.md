# ЛР4 по операционным системам

Bash-скрипт обрабатывает данные о результатах тестов, досье и посещаемости студентов. Данные передаются отдельным каталогом.

## Запуск без Dialog

Откройте терминал в каталоге проекта. Вместо `/path/to/labfiles-3-26` укажите путь к каталогу данных.

```bash
bash lab4.sh help
bash lab4.sh menu /path/to/labfiles-3-26
bash lab4.sh top /path/to/labfiles-3-26 A-06-21
bash lab4.sh tries /path/to/labfiles-3-26 A-06-21 Цирковое_Дело 1
bash lab4.sh dossier /path/to/labfiles-3-26 Anasenko
bash lab4.sh best /path/to/labfiles-3-26 A-06-21 Цирковое_Дело
bash lab4.sh attend /path/to/labfiles-3-26 A-06-21 1 18
```

Первый аргумент — режим, второй — путь к каталогу данных ЛР3. Путь может содержать пробелы, если взять его в кавычки. `menu` запрашивает параметры в терминале и позволяет последовательно запускать режимы. Внешний пакет `dialog` для работы не требуется.

## Режимы

- **top**: по группе считает оценки 5, 4 и 3 отдельно, по всем предметам и тестам. Суффиксы оценок (`5+`, `4-` и другие) отбрасываются. Для каждой оценки выводится один студент с наибольшим количеством и перечень тестов его попыток. При равенстве выбирается первый в списке группы.
- **tries**: по группе, предмету и номеру теста 1–4 выводит всех студентов из списка группы по убыванию количества попыток. Считаются успешные и неуспешные попытки; студенты без попыток получают ноль. При равенстве сохраняется порядок списка группы.
- **dossier**: ищет в `students/general/notes/*.log` всех студентов, чьё ФИО начинается с введённой строки, и печатает их заметки.
- **best**: по группе и предмету для каждого года находит одного студента с наибольшей суммой правильных ответов по всем тестам. Считаются только успешные попытки (оценки 3–5 после удаления суффиксов); выводятся суммы по каждому тесту для проверки общего результата. При равенстве выбирается первый встретившийся результат.
- **attend**: по группе и интервалу пар от 1 до 18 выводит посещаемость отдельно для каждого предмета. Студенты упорядочены по убыванию числа посещённых пар. Даты тестов в расчёте не используются.

Коды завершения: `0` — успешный вывод, `1` — ошибка аргументов, `2` — отсутствует каталог или нужный файл данных. Отсутствие совпадений в записях не считается ошибкой.

## Данные и расположение файлов

Скрипт `lab4.sh` находится в корне проекта. Каталог `labfiles-3-26` передаётся при запуске и не хранится в репозитории. Внутри него ожидаются `students/groups/<группа>`, `students/general/notes/*.log`, каталоги двух предметов `Цирковое_Дело` и `Пересдачеведение` с `tests/TEST-1`–`TEST-4` и файлами `<группа>-attendance`. В строках тестов: `группа;ФИО;дата;правильные_ответы;оценка`. В строках посещаемости: `ФИО 0101...` (18 цифр).

## Интерфейс Linux Dialog

`dialog` показывает меню и окна прямо в терминале. Рабочий стол Linux, X11 и отдельное графическое окно не нужны. На любом компьютере понадобится сам каталог проекта и каталог данных `labfiles-3-26`. Данные лежат отдельно от проекта. Если их нет, получите копию у команды или преподавателя.

Запускайте команды из каталога проекта. Вместо пути в примерах укажите **полный путь к своему каталогу данных**. Если в пути есть пробелы, оставьте кавычки.

### Если у вас Linux

Откройте терминал. На Debian или Ubuntu установите Dialog и запустите меню:

```bash
sudo apt update
sudo apt install dialog
cd /путь/к/lab4_os
bash dialog.sh "/путь/к/labfiles-3-26"
```

На другом дистрибутиве установите пакет `dialog` его штатным менеджером пакетов, затем выполните последние две команды.

### Если у вас Windows

Проще всего запустить Linux через WSL. Если WSL ещё нет, откройте PowerShell **от имени администратора**, выполните команду ниже и перезагрузите компьютер:

```powershell
wsl --install
```

После перезагрузки откройте Ubuntu и создайте пользователя, если программа попросит. В появившемся терминале выполните:

```bash
sudo apt update
sudo apt install dialog
cd "/mnt/c/Users/ВАШЕ_ИМЯ/путь/к/lab4_os"
bash dialog.sh "/mnt/c/Users/ВАШЕ_ИМЯ/путь/к/labfiles-3-26"
```

Путь `C:\Users\...` внутри WSL начинается с `/mnt/c/Users/...`. Для диска `D:` используется `/mnt/d/`. Если проект и данные уже лежат в домашнем каталоге Ubuntu, используйте их обычные Linux-пути.

### Если у вас macOS

Установите и запустите Docker Desktop. Откройте Terminal и перейдите в каталог проекта. Затем укажите путь к данным и запустите временный Linux-контейнер:

```bash
cd "/путь/к/lab4_os"
DATA_DIR="/путь/к/labfiles-3-26"
docker run --rm -it -e TERM=xterm \
  -v "$PWD:/work:ro" -v "$DATA_DIR:/data:ro" \
  -w /work debian:bookworm-slim \
  bash -lc 'apt-get update -qq && apt-get install -y -qq dialog && bash dialog.sh /data'
```

При первом запуске Docker загрузит Linux-образ. Каталоги проекта и данных подключаются к контейнеру только для чтения. После выхода контейнер удаляется; при следующем запуске команда снова установит `dialog` внутри нового контейнера.

### Как пользоваться меню

Выберите функцию стрелками и нажмите Enter. Введите запрошенные значения. Esc или кнопка Cancel возвращает к выбору функции; пункт «Выход» завершает работу. Если путь к данным не передан, программа попросит ввести его. Если окно не помещается, увеличьте размер терминала. Для запуска без Dialog используйте `bash lab4.sh help`.
