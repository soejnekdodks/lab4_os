## От команды до отчёта

В `bash lab4.sh tries "$DATA" A-06-21 Цирковое_Дело 1` первый аргумент выбирает расчёт, второй указывает каталог ЛР3, остальные задают фильтр. Скрипт проверяет аргументы, читает список группы и файл выбранного теста, считает строки по студентам и выводит всю группу. Текстовое меню и Dialog вызывают ту же команду. Примеры остальных запросов и установка для трёх платформ приведены в [README](../README.md).

## Как считаются результаты

- **Группа.** `load_group` читает по одному ФИО в массив `NAMES`. Позиция студента задаёт индекс в массивах счётчиков. При чтении теста проверяются группа и ФИО, поскольку одинаковые имена встречаются в разных группах.
- **Оценки и попытки.** `top` отбрасывает знаки после цифры, отдельно считает пятёрки, четвёрки и тройки и запоминает файлы попыток. `tries` считает каждую строку выбранного теста. Общая функция `sort_counts` переставляет соседние индексы только при строгом превосходстве счётчика справа. Студенты с одинаковым результатом сохраняют порядок списка группы.
- **Досье.** После разделителя из знаков `=` идут ФИО и строка заметки. `dossier` сравнивает начало ФИО с запросом. Запрос `Bondar` также находит `Bondarenko`. Повторные заметки одного студента выводятся все.
- **Результаты по годам.** `best` принимает предмет без группы, берёт год из даты успешной попытки (оценка 3, 4 или 5) и добавляет правильные ответы к сумме студента за год и счётчику теста. Для каждого года среди всех групп выводятся максимум и четыре слагаемых. При равенстве остаётся первый найденный студент с этой суммой.
- **Посещаемость.** `attend` читает по одному файлу посещаемости на предмет. Первая цифра относится к первой паре. Срез включает обе границы, процент округляется вниз. Даты попыток в расчёте не участвуют.

Например, внутри цикла по парам переводим номер пары в индекс строки и проверяем отметку:

```bash
position=$((pair-1))              # Для пары 1 индекс равен 0.
char=${visits:position:1}         # Одна отметка из файла посещаемости.
if [ "$char" == "1" ]; then
    COUNTS[$INDEX]=$((COUNTS[INDEX]+1))  # Ещё одна посещённая пара.
fi
```

## Решения по ходу разработки

Сначала появился каркас команд и расчёт лидеров по оценкам. После уточнений заказчика добавились выбор предмета и теста, поиск досье по началу ФИО, годовые суммы по успешным попыткам и отдельный отчёт о посещаемости каждого предмета. Названия двух предметов и номера тестов 1–4 соответствуют формату задания.

При проверке меню тестировщик отметил повтор названия предмета, ручной ввод его имени, позднее сообщение о неизвестной группе и поведение Ctrl+D. Теперь меню проверяют группу сразу после ввода. В текстовом меню предмет можно выбрать цифрой. В Dialog строка меню показывает одно название, а Ctrl+D завершает сеанс. За привязку клавиши отвечает `dialog.rc`.

Перед `top` и `best` функция `check_tests` проверяет все восемь файлов. Отсутствующий или недоступный для чтения тест даёт сообщение с полным путём в stderr и код 2 до вывода результатов. Для `tries` нужен только выбранный тест. Пустой файл может означать отсутствие попыток и сам по себе допустим.

```bash
# Проверяются тип файла и право на чтение.
if [ ! -f "$path" ] || [ ! -r "$path" ]; then
    error "нужен доступный файл теста: $path" 2
fi
```

Полный код с пояснениями находится в [lab4.sh](../lab4.sh) и [dialog.sh](../dialog.sh). Первичные сценарии проверки и записи работы интерфейса собраны в [отчёте тестировщика](../tests/Tests%20analyse.md).
