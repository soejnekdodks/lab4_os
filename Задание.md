# Лабораторная работа №4 по операционным системам

## 1. Общее задание
Лабораторная работа №4 выполняется всей бригадой и требует разработки одного или нескольких bash/shell скриптов. Для этого участникам бригады необходимо распределить между собой роли: менеджера, аналитика, разработчика и тестировщика.

Преподаватель (далее — заказчик) выдвигает функциональные требования к разрабатываемому Решению под ОС Linux. В качестве предметной области и исходных данных выступает Файловая Система Преподавателя из Лабораторной работы №3.

Конкретные индивидуальные требования должны уточняться менеджером или аналитиком бригады лично с заказчиком. Представителю бригады необходимо связаться с заказчиком для уточнения индивидуальных требований.

В качестве отчетности, кроме демонстрации заказчику работоспособных скриптов, необходимо предоставить:
- краткую документацию решения (в электронном виде);
- отчет о проведенном тестировании (в электронном виде);
- документировать основные моменты разработки.

## 2. Функциональные требования (индивидуальное задание)

### 2.1. Базовое решение (для успешной сдачи)
Базовое решение должно предоставлять следующие возможности по заданному пользователем номеру группы:
- вывод имени студента с максимальным количеством пятерок/четверок/троек по тестам, вывод таких результатов;
- вывод списка группы, упорядоченного по количеству попыток сдачи теста.

### 2.2. Дополнительные требования (для отличной оценки)
В рамках решения также необходимо реализовать:
- вывод по фамилиям студентов их досье;
- вывод студентов с наилучшими результатами (по количеству правильных ответов) за каждый год сдачи теста;
- вывод списка студентов, упорядоченного по средней посещаемости за заданный интервал времени.
