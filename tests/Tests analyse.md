### Искусственные данные
Основные данные находятся в `fixtures/labfiles-3-26`. В группе `G-1` пять студентов. Группа `G-0` нужна для случая без попыток. Все ФИО вымышлены.

Запуск команд:

```bash
bash lab4.sh top fixtures/labfiles-3-26 G-1
bash lab4.sh tries fixtures/labfiles-3-26 G-1 Цирковое_Дело 1
bash lab4.sh dossier fixtures/labfiles-3-26 Ann
bash lab4.sh best fixtures/labfiles-3-26 G-1 Цирковое_Дело
bash lab4.sh best fixtures/labfiles-3-26 G-1 Пересдачеведение
bash lab4.sh attend fixtures/labfiles-3-26 G-1 1 5
```

Контрольные значения:
- `top`: по оценке 5 максимум равен 2. Его делят `Anna`, `Boris` и `Vera`; допустим один из них. По оценке 4 лидер `Boris` с 2, по оценке 3 `Boris` с 3.
- `tries`: у `Anna` и `Boris` по 2 попытки, у `Vera` 1, у `Annabelle` и `Zero` 0. Запись `Anna` из другой группы не должна попасть в расчёт.
- `dossier`: по `Ann` найдены `Anna` с двумя заметками и `Annabelle` с одной.
- `best`, `Цирковое_Дело`: за 2024 год у `Boris` сумма 43, за 2023 год 28. Неуспешная попытка `Vera` с 20 правильными ответами за 2023 год не учитывается.
- `best`, `Пересдачеведение`: за 2024 год лидер `Vera` с 30, за 2025 год `Boris` с 21.
- `attend`, пары 1–5: для `Цирковое_Дело` у `Anna` и `Annabelle` 5/5, у `Boris` 3/5, у `Vera` и `Zero` 0/5. Для `Пересдачеведение` у `Boris` 5/5, у `Vera` 3/5, у `Annabelle` 1/5, у `Anna` и `Zero` 0/5.

### Замечания
1) Довольно неудобно целиком вводить предмет. Целесообразно предложить пользователю выбор с помощью ввода цифры - 1 или 2, что соответствует выбранному предмету.
![[Pasted image 20261112004050.png]]
2) В графческом режиме Предметы отзеркаливаются для любого режима работы
![[Pasted image 20261112010359.png]]

3) При некорректном вводе группы программа всё ещё продолжает работу и запрашивает название предмета в котором требуется выполнить поиск. Стоит обновлять группу динамически и сразу выводить сообщение об ошибке.

	нажимаю ctrl+D (EOF) - обычно должно привести к выходу из программы

	***Примечание*** -  Программа и далее работает с данными. Выход ctrl+C работает.
